# Mapa de Carved in Stone

Mapa del servidor de Minecraft **Carved in Stone** (Minecraft 1.21.1, NeoForge), dibujado por el mod [Diorama](https://modrinth.com/mod/diorama-map).

**👉 Ver el mapa: https://thearchery.github.io/carved-in-stone-mapa/**

- Solo el Overworld (la superficie).
- Se actualiza solo, cada 6 horas, desde el servidor.
- Rueda del ratón para acercar y alejar; arrastra para moverte.

Los archivos del mapa están en la rama [`gh-pages`](https://github.com/THEARCHERY/carved-in-stone-mapa/tree/gh-pages).
